   weights unpacked per 16-row panel and K segment into zmm = 16 rows x 4 consecutive k as u8 = kv+12 (16x8 dword transpose of the nibble bytes,
   32 shuffles + 40 nibble uops + 12 scale uops per 16 rows x 64 k), activations = the existing NVFP4 pack (same lane permutation: the
   4 k of (sub-block s, quad q) sit at byte 4*(4q+s) of the 64-byte chunk, so vpbroadcastd just uses that offset) + a new int32 array
   xb[t][sb] = 12*sum(x) per sub-block (format GEMM_FMT_I16 = NVFP4 pack + xb; the exact kernels accept it too).

   Float order: acc_t = fma(fl(fma(cvt(I1), sw1, fl(cvt(I0)*sw0))), dx, acc_t) per block, sequential over blocks (independent of tile and segment).
