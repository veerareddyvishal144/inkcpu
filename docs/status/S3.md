- Design decisions after reading the code (details will go to docs/REWIND.md):
  * Recurrent state = pos + 48 conv histories (3.83 MB) + KV only (controllers, message bank, block states live in the per-token Scratch;
    S2's verify rollback relies on the same fact and is tested bit-exactly).
  * SWA ring = 2048 cells, window 1024 (visible distances 0..1023). Positions needed after a rewind to P: [P-1023, P-1]. k appended
    tokens overwrite cells formerly holding P-2048..P+k-1-2048; conflict iff k >= 1026. RESTORABLE (shallow) iff hwm - P <= 1025,
    where hwm = highest position ever written since reset (NOT the live pos: a previous rewind may have left junk in older cells).
    1025 = ring - (window - 1) = exactly the existing prefill `chunk_limit` bound, so the chunk interaction is already covered.
  * Checkpoint kinds: shallow (pos + hist copy, 3.83 MB; automatic at every prefill chunk end and at the end of every multi-token
    forward; explicit via ink_slot_checkpoint) and DEEP (adds a copy of the SWA window cells [P-1023, P-1] of the 40 SWA visits,
    167.6 MB; explicit via ink_slot_checkpoint_deep, meant for the prompt end: restorable regardless of how many tokens were
    generated after it, which the shallow kind cannot do once a generation exceeds 1025 tokens). Per-slot store: ring of
    INK_CKPT_MAX (default 8) entries, at most INK_CKPT_DEEP (default 2) deep; shallow entries that fell out of the 1025 bound are dead
    forever (hwm never decreases) and are evicted first.
  * Rewind drops every checkpoint above the rewound position; global KV rows > P are junk and get overwritten (n_blocks grow-only as today).
    The drafter (S2) notices the position mismatch in its tap sink and marks the slot unsynced (plain steps until reset): no spec change needed.
  * Server: full-prefix path first; else largest token-level LCP >= --prefix-reuse-min (default 1024) -> ink_slot_rewind(slot, LCP)
    -> history = tokens[:P], prefill prompt[P:], cached_tokens = P; chunks are split so one ends exactly at the LCP (a checkpoint lands
    where threads diverge); deep checkpoint at prompt end, shallow at generation end; LRU reset remains the fallback.
