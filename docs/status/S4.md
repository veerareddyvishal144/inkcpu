## Mapping rules implemented
See `docs/ENGINE.md` "GGUF layouts". In short: arch `inkling2` -> block_count = visits, `num_loops` / `loop.core_{start,end}`,
physical layers = visits - (num_loops-1)*core, per-visit arrays in llama.cpp slot order (first 24 entries = physical layers, repeats
checked), controller renames q/k/v/ffn_ctrl -> attn/k/v/mlp, per-layer msg_query [2304,4] (Q,K,V,FFN) assembled from
`loop_res_query` (Q=2i, FFN=2i+1) and `loop_kv_res_query` (K=2i, V=2i+1), i = layer-6.
